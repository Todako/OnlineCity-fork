# Discord-бот для моду "Online City"
Увага! Бот існує в єдиному екземплярі на всі сервери "Online City"

## Реєстрація сервера
Після того як бота буде додано на сервер Discord, він почне слухати всі канали сервера, куди його було додано.
Якщо в одному з каналів ввести команду
```sh
OC! Reg IP_Server:Port Bot_Token

```

то на цьому каналі реєструється бот і починає ретранслювати повідомлення із зазначеного сервера Online City.
Щоб дізнатися токен сервера Online City, введіть у грі команду:

```sh
/Discord ServerToken

```

!Важливо: у бота мають бути права на читання та запис цього каналу

У відповідь буде надано токен сервера. Нікому його не розголошуйте та проводьте реєстрацію, спочатку зробивши канал чату в Discord приватним.
Після успішної реєстрації повідомлення буде автоматично видалено, і тоді канал можна відкрити для всіх.

Діють такі обмеження:
* Один канал Discord — один сервер "Online City".
* Якщо сервер недоступний понад 10 хвилин, людині, яка його зареєструвала, надсилається приватне повідомлення про те, що сервер недоступний і необхідно вжити заходів. Після спливу першої години сповіщення надходитимуть щогодини протягом доби. Якщо заходів не вжито, реєстрація сервера буде автоматично видалена через 7 днів після того, як сервер став недоступним або пов'язаний із ним канал Discord було видалено.

## Реєстрація користувача
Якщо ви хочете надіслати повідомлення в гру, спершу потрібно зареєструватися:
надішліть у ПРИВАТНОМУ повідомленні боту:
```sh
OC! regme MyToken

```

Бот сам знайде, на якому сервері Online City є користувач із таким токеном, і в якому каналі дозволити йому надсилати повідомлення.
Усі неавторизовані повідомлення із зареєстрованого каналу автоматично видалятимуться ботом для запобігання флуду.

Щоб дізнатися свій токен, введіть у грі команду:
```sh
/Discord

```

У відповідь буде надано ваш токен. Нікому його не розголошуйте та реєструйтеся лише через приватний чат бота.

Щоб дізнатися всі доступні команди, наберіть:
```sh
!OC help

```
